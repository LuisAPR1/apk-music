Recuperação
===========
Classes Java e recursos extraídos com JADX 1.5.6. As 18 classes de aplicação
foram recuperadas; R é gerada novamente a partir dos recursos.
MainActivity, definições, cores, gestos, brilho, volume, bloqueio e temporizador
foram recuperados do APK. MediaBridge e MediaAccessService foram reconstruídos
com o código legível da base Git e as extensões verificadas no APK 1.5:
artista nos metadados/notificações e pausa da sessão pelo temporizador.
Foram corrigidos artefactos da descompilação: referências de callbacks,
variáveis capturadas e o fluxo do cálculo de posições no PlayerLayout.
O fluxo de onLayout foi confrontado com as instruções DEX originais.
Os nomes de métodos auxiliares foram tornados legíveis.
Não se recuperaram os commits nem o texto exato do código original.

Compilação efetuada
==================
Comando:
python build.py --sdk-root /workspace/.toolchain/sdk --ecj /workspace/.toolchain/ecj.jar
Java 21, ECJ 3.38.0, Android SDK Platform 36 rev. 2,
Android Build Tools 36.0.0, bytecode Java 8, minSdk 26, targetSdk 36.
Todo o Java foi compilado, convertido para DEX e incluído num novo APK.
Os recursos foram compilados e ligados novamente por aapt2.
Não foi usado o classes.dex do APK 1.5 na construção da 1.6.
build.ps1 foi atualizado para ler a versão de app/build.gradle; não foi
executado, pois este ambiente é Linux. A via Gradle também não foi executada.
