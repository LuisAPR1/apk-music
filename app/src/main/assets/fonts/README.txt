Bundled fonts
=============

These unmodified fonts are distributed under the SIL Open Font License 1.1.
Their copyright notices and complete license texts are included in licenses/.
The app bundles these files so that typography works without network access.

Source: https://github.com/google/fonts/tree/main/ofl/
Downloaded: 2026-11-05

Local file               Upstream family / file
Quicksand.ttf             quicksand/Quicksand[wght].ttf
Oswald.ttf                oswald/Oswald[wght].ttf
PlayfairDisplay.ttf       playfairdisplay/PlayfairDisplay[wght].ttf
DancingScript.ttf         dancingscript/DancingScript[wght].ttf
BebasNeue.ttf             bebasneue/BebasNeue-Regular.ttf

The first four are variable fonts using their default axis values. Android may
synthesize bold and italic when the chosen face does not supply that style.
